FAQ

Common questions.

Is Pc-Cheak an anti-cheat?

It is an integrity-checking tool that helps FiveM staff review PC and Windows indicators. It should complement, not replace, server-side anti-cheat and moderation.

Does the player need to give consent?

Yes. The workflow is explicitly consent-based before a scan is performed.

Does Pc-Cheak inject into FiveM?

No. The scanner is designed to collect Windows/system integrity signals without injecting code into the game.

Can everyone download it?

Yes. The website can be public. Scanning can remain protected by activation keys issued by your authorized staff.
